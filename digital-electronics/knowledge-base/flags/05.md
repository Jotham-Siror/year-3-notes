# Verification flags — 05 — Analogue-to-Digital Conversion

Source: `CH4`, slides 1–29 of 49. Every equation, table, code sequence and figure in that range was
checked for dimensional and algebraic consistency, symbol slips, mislabelled results and
self-reference, and **every numerical claim was recomputed in Python**: the slide-5 PCM bit stream,
the slide-12 and slide-13 quantisation tables (including a cross-check that one is the other divided
by four and truncated), the slide-15 comparator count and step size, the slide-16/17 flash example
end to end for all twelve pulses and all three output bits, every node voltage and every branch of
the slide-22 successive-approximation tree, and every clock-count entry in the slide-28 comparison
table.

**Ten defects found: five substantive, five cosmetic.**

## Substantive

### V05-1 · CH4 slide 20

**Prints:** "Vin > VDAC: Comparator output goes low. The bit in the SAR goes low as well.
Vin < VDAC: Comparator output goes high. The SAR keeps that bit high."
**Should be:** $V_{\text{in}} > V_{\text{DAC}}$ → comparator output HIGH → the trial bit is **kept**;
$V_{\text{in}} < V_{\text{DAC}}$ → comparator output LOW → the trial bit is **cleared**.
**Why:** three independent checks in the same deck contradict the annotation. Slide 19 states "If
the input is larger, the bit is retained; otherwise it is reset (0)". Slide 21's flowchart routes
the **yes** branch of $V_{IN} > V_{DAC}$ to "set the bit". And slide 20's own schematic puts
$V_{\text{in}}$ on the non-inverting (+, pin 3) input and the DAC output on the inverting (−, pin 2)
input, so the output must be HIGH when $V_{\text{in}}$ is the larger. Taken as printed, the
converter would return the ones-complement of the correct code.
**Class:** substantive — it inverts every bit of every conversion, and it is the slide a student
reads while looking at the block diagram.

### V05-2 · CH4 slide 22 (right-hand tree)

**Prints:** the second-level node on the "Vin>VDAC" branch as **0100**
**Should be:** **1100**
**Why:** 0100 is already drawn as the node on the opposite ("VDAC>Vin") branch, so the tree has two
identical siblings; and the two children drawn beneath the lower node are 1010 and 1110, which are
reachable only from 1100 (clear bit 2 and set bit 1 → 1010; keep bit 2 and set bit 1 → 1110). From
0100 the children would be 0010 and 0110. A trial that found the input **above** half scale cannot
lead to a code below half scale.
**Class:** substantive — the whole lower half of the tree is unreachable from the node as printed.

### V05-3 · CH4 slide 22 (left-hand worked path)

**Prints:** the branch rejected at the fourth trial as **1010 / 6.25 V**
**Should be:** **1001 / 5.625 V**
**Why:** the fourth trial code is 1001. Its only two outcomes are 1000 (bit 0 cleared, 5.000 V) and
1001 (bit 0 kept, 5.625 V). 1010 was the *third* trial and cannot recur as a fourth-trial outcome.
The slide's own right-hand tree confirms it: the two leaves under 1001 are 1000 and 1001. Check by
recomputing the DAC voltages with the step the slide's own circles imply,
$5.000/8 = 0.625\ \text{V}$: $1001_2 = 9 \times 0.625 = 5.625\ \text{V}$, while
$1010_2 = 10 \times 0.625 = 6.250\ \text{V}$ is the trial-3 value already drawn one column to the
left.
**Class:** substantive — a student tracing the algorithm from this figure learns a step the
algorithm cannot take.

### V05-4 · CH4 slide 28

**Prints:** dual slope — "No. of Clocks" $2^{n} + 1$, "Conversion Time" $(2^{n} + 1) \times
T_{\text{CLK}}$
**Should be:** $2^{\,n+1}$ clocks, $2^{\,n+1} T_{\text{CLK}}$
**Why:** the exponent has lost its bracket — $2^{(n+1)}$ has been set as $2^{n} + 1$. The dual-slope
converter integrates the input for a fixed period of $2^{n}$ clocks (the counter runs a full cycle),
then de-integrates for up to $2^{n}$ more, so the worst case is $2 \times 2^{n} = 2^{\,n+1}$. The
printed and correct values diverge sharply at the resolutions the same row quotes: at $n = 12$,
$2^{n}+1 = 4097$ against $2^{\,n+1} = 8192$; at $n = 16$, $65537$ against $131072$. The neighbouring
rows are unaffected and were confirmed correct ($2^{n}-1$ for the counter type, 1 for flash, $n$ for
SAR, $2^{n}$ for sigma-delta).
**Class:** substantive — a factor of roughly two in the headline figure for the converter, and the
row is the one most likely to be examined as a comparison question.

### V05-5 · CH4 slide 26

**Prints:** "With sigma-delta conversion, the difference between two samples of the analog input
signal integrated and quantized."
**Should be:** the difference between the analogue input and the **fed-back analogue value of the
quantised output** is integrated and quantised.
**Why:** the slide's own block diagram shows the summing point with the analogue input on **+** and
the 1-bit DAC output on **−**. Nothing in the loop stores a previous input sample, so no
input-to-input difference can be formed. As printed the description is of a plain delta modulator
without the feedback DAC, which is a different converter.
**Class:** substantive — it misdescribes what the loop computes, and the loop is the whole idea.

## Cosmetic

### C05-1 · CH4 slide 23

**Prints:** $\text{Digital out} = \left(\frac{V_{in}}{V_{red}}\right) \times (2^{n} - 1)$, and
numbers its fourth list item "i." after i, ii, iii
**Should be:** $V_{REF}$ in the denominator; the fourth item numbered iv
**Why:** $V_{red}$ is defined nowhere in the chapter; the same question's opening line names the
reference voltage $V_{REF}$ and gives it as 5 V. The formula is dimensionally sound once the symbol
is read correctly.
**Class:** cosmetic — the intent is unambiguous, but the question is set homework, so the symbol
will be copied.

### C05-2 · CH4 slide 28

**Prints:** "Couter Type / Digital Ramp"
**Should be:** "Counter Type / Digital Ramp"
**Why:** spelling; the same converter is spelled correctly on slide 29.
**Class:** cosmetic.

### C05-3 · CH4 slide 8

**Prints:** prose "the sampling rate must be **greater than** twice the maximum frequency present in
the signal", then a bullet saying "at least twice", then the formula $f_s \ge 2f_{max}$
**Should be:** one or the other consistently; the strict recovery condition is $f_s > 2f_{\max}$
**Why:** the prose and the printed formula disagree on whether equality is allowed. At exactly
$f_s = 2f_{\max}$ a component at $f_{\max}$ can be sampled at its zero crossings and disappear
entirely, so the strict inequality is the safe statement; $\ge$ is the common engineering shorthand
and is what the formula prints.
**Class:** cosmetic — the working rule ("sample at twice the highest frequency or more") is
unaffected, but the two statements sit four lines apart.

### C05-4 · CH4 slide 7

**Prints:** "Analog signal is sampled every $T_S$ secs", $f_s = 1/T_s$, then "x[n] is obtained by
extracting x(t) every $T$ s where $T$ is known as the sampling period or interval"
**Should be:** one symbol for one quantity — $T_s$ throughout
**Why:** $T_S$ and $T$ are the same interval, introduced twice on one slide. Slide 8 then uses $T$
alone in $T \le 1/(2f_{max})$. Harmless until $T$ collides with $T_{\text{CLK}}$ and with the
dual-slope phase times $T_1$, $T_2$ later in the chapter.
**Class:** cosmetic — notation only.

### C05-5 · CH4 slide 15

**Prints:** "It uses $2^n$ - 1 comparators for an n-bit resolution ADC", then two lines later
"Resolution $\Delta V = V_{ref}/2^{N}$"
**Should be:** the same case of the letter in both — $n$
**Why:** $n$ and $N$ are the same bit count. The two formulas already differ in a way that looks
like a typo ($2^n - 1$ against $2^n$) but is not — see the note in §5.8 of the topic file — so a
gratuitous case change on the same slide is worth removing.
**Class:** cosmetic — notation only.

## Checked and found correct

Recorded here so that the checks are not repeated:

- Slide 5's coded bit stream, $100110101011001001010$, is exactly the seven levels 4, 6, 5, 3, 1, 1,
  2 encoded in three bits each — 21 bits, all matching.
- Slide 12's thirteen two-bit codes and slide 13's thirteen four-bit codes all reproduce, and the
  two tables are mutually consistent (slide 12's level equals slide 13's level divided by four and
  truncated, interval by interval).
- Slide 15's $2^n - 1$ comparator count and $V_{\text{REF}}/2^n$ step size are **both** right and are
  not in conflict: $2^n$ equal ladder resistors give $2^n - 1$ internal taps. This was the specific
  levels-versus-steps confusion looked for; it is not present here.
- Slides 16–17: step size $8/8 = 1\ \text{V}$; all twelve codes and all three output-bit waveforms
  reproduce exactly.
- Slide 22: every circle's voltage is consistent with a single step of 0.625 V (DAC full scale
  10 V), and the ticked path is a valid four-trial search for any input in
  $5.000\ \text{V} \le V_{\text{in}} < 5.625\ \text{V}$.
- Slide 26's density figure: 4096 ones at $+\text{MAX}$, 2048 at mid-scale, 0 at $-\text{MAX}$ over a
  4096-clock window — internally consistent.
- Slide 28's other four rows: $2^n - 1$ (counter type), 1 (flash), $n$ (SAR), $2^n$ (sigma-delta) all
  correct.
