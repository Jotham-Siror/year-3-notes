# Verification flags — 07 — FSM Fundamentals and Sequential Circuit Analysis

Source: `CH5` slides 1–38 of 118, and `EXC`, the one-page excitation-table handout.

**Method.** Every slide in the range was read as a rendered image, never from the text layer. Every
state table, state diagram, flip-flop-input table, Karnaugh map and algebraic expansion in the
range was rederived in Python from the stated next-state and output equations and compared cell by
cell against the deck. Specifically: the serial-adder state tables and logic equations (slides
15–17); the two-D-flip-flop state table, second-form table and state diagram (slides 21–24); the
D flip-flop analysis $A(t+1) = A \oplus x \oplus y$ (slides 26–27); the JK analysis, all four
flip-flop-input columns and both next-state columns, and its state diagram (slide 29); both
characteristic-equation expansions (slide 30); the T flip-flop analysis, its algebraic expansion
and its Moore state diagram (slide 31); the three-D-flip-flop state table and state diagram
(slides 32–33); the equivalence reduction, checked both by partition refinement and by exhaustive
simulation of all 2046 input strings up to length 10 (slides 35–36); the Moore and Mealy tables
against their diagrams (slide 37); the mixed-output diagram against the slide-21 state equations
(slide 38); and all four excitation tables against their own characteristic tables (`EXC`).

**Result: three substantive defects, four cosmetic.** Everything else in the range checked out —
all eight rows of every state table, all thirty-two flip-flop-input entries on slide 29, both
K-maps on slide 17, and every transition in every state diagram.

### V07-1 · CH5 slide 17

**Prints:** $z \;=\; \bar{a}b\bar{s} \;+\; a\overline{bs} \;+\; \overline{ab}s \;+\; abs$ — the
second and third terms carry a **single continuous overbar spanning two letters**.

**Should be:** $z \;=\; \bar{a}\,b\,\bar{s} \;+\; a\,\bar{b}\,\bar{s} \;+\; \bar{a}\,\bar{b}\,s \;+\; a\,b\,s \;=\; a \oplus b \oplus s$

**Why:** $\overline{bs} = \bar b + \bar s \neq \bar b\,\bar s$. Evaluating the printed expression
literally over $(a,b,s) = 000 \ldots 111$ gives $0,1,1,1,1,1,1,1$; the correct sum-of-minterms
gives $0,1,1,0,1,0,0,1$, which is what the slide's own Karnaugh map and slide 16's state table
both show. The first and fourth terms on the same line use individual bars, so the slide is
internally inconsistent as well.

**Class:** substantive — read as printed the expression is a different Boolean function, and a
student copying the notation into a CAT answer would be marked wrong.

### V07-2 · CH5 slide 33

**Prints:** $A = BC$, $B = B'C + BC'$, $C = A'C'$, $Z = A$

**Should be:** $D_A = BC$, $D_B = B'C + BC' = B \oplus C$, $D_C = A'C'$, $Z = A$ — equivalently
$A(t+1) = BC$, $B(t+1) = B \oplus C$, $C(t+1) = A'C'$.

**Why:** self-reference. $B$ appears on both sides of the second equation and $C$ on both sides of
the third, so as ordinary Boolean equations they have no solution — $B = B'C + BC'$ requires
$B = B \oplus C$, which forces $C = 0$. What is meant is the flip-flop **input** equations. Only
$Z = A$ is well-formed as printed, because $Z$ is a combinational output rather than a state
variable. The state table on the same slide is computed from the intended reading and is correct.

**Class:** substantive — the equations as printed are false, and the same page's state table
depends on the corrected reading.

### V07-3 · EXC, T flip-flop section

**Prints:** the T flip-flop **characteristic table** with its input column headed **$D$**:
$D = 0 \Rightarrow Q(t+1) = Q(t)$ (no change), $D = 1 \Rightarrow Q(t+1) = Q'(t)$ (toggle).

**Should be:** the column is **$T$**.

**Why:** the section is headed "T Flip-flop", the excitation table beside it uses $T$, and the
behaviour described is toggling. A D flip-flop does not toggle: for a D flip-flop
$Q(t+1) = D$, so $D = 1$ gives $Q(t+1) = 1$, not $Q'(t)$. The D flip-flop's own characteristic
table appears correctly two sections higher on the same page, which makes the clash worse — the
page prints two different tables both headed $D$.

**Class:** substantive — this page is the most-consulted table in the unit, and the mislabelled
column contradicts the D flip-flop table printed above it.

### C07-1 · CH5 slide 17

**Prints:** $s' = ab\bar{s} + \bar{a}bs + a\bar{b}s + abs$ — the canonical four-minterm sum —
while the Karnaugh map immediately above it is grouped into three overlapping pairs.

**Should be:** the three groupings read out as $s' = ab + bs + as$, the minimal form and the
standard full-adder carry expression.

**Why:** the printed equation and the minimal form describe the same function (both were evaluated
over all eight combinations and agree), so nothing downstream is wrong; but the K-map working shown
on the slide is the working for the minimal form, and the equation printed beneath it is not that
form. The equation for $z$ on the same slide *is* minimal, because an exclusive-OR admits no
simplification, so only the $s'$ line is affected.

**Class:** cosmetic — the answer is correct, but the K-map grouping and the printed equation do not
correspond, and the unminimised form costs two extra gates if implemented literally.

### C07-2 · CH5 slide 28

**Prints:** $D = JQ' + K'Q$ and $D = T \oplus Q = T'Q + TQ'$

**Should be:** $Q(t+1) = JQ' + K'Q$ and $Q(t+1) = T \oplus Q = T'Q + TQ'$

**Why:** these are the **characteristic equations of the JK and T flip-flops**, and their left-hand
side is the next state. Writing $D$ there is only meaningful as "the equivalent D input", and
neither a JK nor a T flip-flop has a $D$ input. Slide 31 prints the same T relation correctly as
$Q(t+1) = T \oplus Q$, so the deck contradicts itself.

**Class:** cosmetic — the two forms are numerically identical because $Q(t+1) = D$ for a D
flip-flop, but the symbol on the left is wrong for the flip-flop under discussion.

### C07-3 · CH5 slide 30

**Prints:** $A(t+1) = JA' + K'A$ and $B(t+1) = JB' + K'B$

**Should be:** $A(t+1) = J_A A' + K_A' A$ and $B(t+1) = J_B B' + K_B' B$

**Why:** the two flip-flops have different inputs — $J_A = B$, $K_A = Bx'$, $J_B = x'$,
$K_B = A \oplus x$ — so unsubscripted $J$ and $K$ cannot stand for both. The substitution performed
two lines below uses the correct per-flip-flop values and produces the correct state equations, so
only the notation is at fault.

**Class:** cosmetic — notation only; the derived results $A(t+1) = A'B + AB' + Ax$ and
$B(t+1) = B'x' + ABx + A'Bx'$ were both verified correct over all eight input combinations.

### C07-4 · CH5 slide 33

**Prints:** the state-table column heading $A'\,B'\,C'$ at $(t+1)$, using a prime to mean "next
state" — on the same slide whose equations use a prime to mean "complement" ($C = A'C'$,
$B = B'C + BC'$).

**Should be:** $A(t+1)\,B(t+1)\,C(t+1)$, with the prime reserved for complement.

**Why:** one mark, two meanings, eight lines apart. The table's contents are correct under the
"next state" reading; the ambiguity is in the heading alone.

**Class:** cosmetic — no numerical consequence, but it is the kind of clash that turns into a lost
mark when a student reproduces the notation under time pressure.

  textbook. Both have been **redrawn** from scratch as SVG rather than reproduced, because a reader
  must reason from them; no third-party image is committed.
- Slide 32's schematic is a hand-drawn scan. It has also been redrawn. The redrawing was checked
  against the equations printed on slide 33 rather than traced pixel by pixel — worth a second pair
  of eyes on the gate-level detail, though the electrical behaviour is fully determined by the four
  equations and those have been verified against the state table.

  example's next state as $A'B'C'$ (slide 33), while using the same prime for complement
  throughout. This clash is worth an entry in `_nomenclature.md`.
