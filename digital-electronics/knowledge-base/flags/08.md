# Verification flags — 08 — Sequential Circuit Design and Sequence Detectors

Source: `CH5`, slides 39–71.

Two substantive defects and six cosmetic ones. **None of them is in a state diagram or a state
table.** All six machines built in this range — Mealy and Moore versions of the 101, the 010/1001
and the 1101 detectors — were rebuilt in software from their printed diagrams and tables, compared
cell by cell in both directions, simulated over every input string of length 1 to 16, and checked
for completeness and reachability. All six are functionally correct. The defects below are in the
surrounding prose.

---

### V08-1 · CH5 slide 53

**Prints:** "Any sequence ending in 101 will produce and output of $Z=1$ **coincident with the last
1 input**." — as the specification for **Example 1b, the Moore machine**.

**Should be:** the output appears during the clock period **after** the one in which the last 1 is
applied. The Moore machine cannot assert $Z$ coincident with the last input.

**Why:** slide 53 is a verbatim copy of the Example 1a (Mealy) specification on slide 44, and the
phrase was not adjusted for the change of model. A Moore output is a function of the state alone,
$Z(t)=\lambda(S(t))$, and the state that means "101 received" ($S_3/1$ on slide 56) is only entered
on the clock edge that samples the last 1. Checked over every input string up to sixteen bits: the
Moore machine of slide 56 produces exactly the output of the Mealy machine of slide 48, shifted one
clock period later — $Z_{\text{Moore}}(t+1)=Z_{\text{Mealy}}(t)$, with no other difference. The
state diagram and state table on slides 55–56 are correct; only the copied sentence is wrong.

**Class:** substantive — a student who takes the sentence at face value will draw a Moore timing
diagram with the pulse in the wrong clock period, which is the single most commonly lost mark in
this topic.

### V08-2 · CH5 slide 54

**Prints:** a bullet headed "**Transitions from State 1**", whose first sub-bullet reads "On a 0 you
stay in **state 1**" and whose second reads "On a 1 you transition to state S1."

**Should be:** "Transitions from **State 0**", and "On a 0 you stay in **$S_0$**".

**Why:** the block is describing the two arcs leaving the reset state $S_0$ — the diagram printed
beside it on the same slide shows the $S_0$ self-loop on 0 and the arc $S_0 \to S_1$ on 1. The very
next block on the same slide then starts again with "Transition from S1", so $S_1$ is covered
separately and cannot also be the subject of this block. Taken literally the printed text gives
$S_1 \to S_1$ on both 0 and 1, a machine with no path to $S_2$ that detects nothing.

**Class:** substantive — the printed words contradict both the diagram beside them and the following
bullet, and following them produces a non-functional machine.

### C08-1 · CH5 slide 42

**Prints:** step 4 of the sequence-recogniser procedure — "The final state represents the input
sequence occurrence (**feasibly** less the final input value)."

**Should be:** "(**possibly** less the final input value)."

**Why:** "feasibly" is a malapropism for "possibly". The intended point is that in a Mealy machine
the final state represents the target sequence **minus its last bit**, because the last bit is
consumed by the arc that carries the output 1 — compare $D$ on slide 68, which means 110, not 1101.

**Class:** cosmetic — one word, but it obscures a step of the procedure.

---

### C08-2 · CH5 slide 43

**Prints:** "Make sure **all state** have a transition for both a 0 and a 1 but only **1of** each!"

**Should be:** "Make sure all **states** have a transition for both a 0 and a 1, but only **1 of**
each."

**Why:** two typographical slips — a missing plural and a missing space. The rule itself is correct
and is the completeness test used on all six machines in this range.

**Class:** cosmetic.

---

### C08-3 · CH5 slides 44 and 53

**Prints:** "…will produce **and** output of $Z=1$…" on both slides, and on slide 44 the paragraph
stops mid-clause: "…so whenever a 101 is in the data stream a 1 is output coincident with the
**last**".

**Should be:** "…will produce **an** output of $Z=1$…", and the sentence completed as "…coincident
with the last **1.**"

**Why:** "and" for "an" is a typing slip. The truncation on slide 44 is a text-box overflow: slide 53
repeats the same paragraph and shows the missing final word.

**Class:** cosmetic — but the truncated sentence leaves the overlap rule looking unfinished on the
slide that first states it.

## Checked and found correct

Recorded here so the checks are not repeated:

- **Slide 45** — the printed pair $X = 0011011001010100$, $Z = 0000010000010100$ over $t=0\ldots15$.
  Regenerated from the slide-48 Mealy machine: identical. $Z=1$ at $t=5,11,13$ only, and the last
  three input bits at each of those instants are 101.
- **Slide 49** — the printed pair over $t=0\ldots16$ with the six markers $a$ to $f$. Regenerated
  from the slide-52 Mealy machine: identical. Detections at $t = 3, 5, 7, 8, 12, 14$, matching the
  six arrow positions; patterns 010, 010, 1001, 010, 010, 1001 respectively.
- **Slides 48, 52, 56, 62, 68, 70** — all six state diagrams: every state has exactly one arc for
  each input value, every state is reachable from the reset state.
- **Slides 56, 57, 63, 69, 71** — all printed state tables agree with their diagrams in every cell,
  checked in both directions.
- **Slide 65** — 1111101 does contain 1101 (bits 4–7); 1101101 does contain 1101 twice (bits 1–4 and
  4–7) sharing the middle 1.
- **Slide 70** — the claim that $E$ "produces the same behaviour in the future as state $B$" holds:
  both go to $A$ on a 0 and to $C$ on a 1, differing only in output.
- **Slides 57, 63, 70** — the claim that the Moore model needs more states than the Mealy model
  holds for all three specifications: 4 against 3, 8 against 6, 5 against 4.

## Unreadable

None. All 33 slides in the range rendered legibly and every figure could be read.

One gap, not a defect: the waveform on **slide 41** does not state which sequence it is detecting.
What can be read from the drawing without guessing is recorded in §8.3 of the topic file — $x$
samples to $0,1,1,0,0$ at the five marked rising edges, and $w$ is drawn as a registered output held
for exactly one clock period after the fourth edge. No target sequence has been inferred.
