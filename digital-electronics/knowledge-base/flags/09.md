# Verification flags — 09 State Reduction and State Assignment

Source: `CH5`, slides 72–118. Three substantive defects, three cosmetic. Everything else in the
range was checked and is correct.

**What was checked.** Every state table, state graph, assignment map, next-state map, K-map,
flip-flop equation, gate count and input/output string on slides 72–118 was rebuilt in Python from
the deck's own specification and compared entry by entry with the print. The implication-table
algorithm was implemented and run on the deck's example, and its chart was compared with the printed
chart cell by cell at every pass. Every state reduction was confirmed independently by partition
refinement **and** by exhaustive behavioural simulation of the original and reduced machines. Every
state assignment was used to rebuild the next-state maps and the flip-flop input equations from
scratch. Both serial-data machines were simulated and their outputs compared with the Manchester
encoding rule of slide 114.

### V09-1 · CH5 slides 77 and 78

**Prints:** in both partial and complete state-tree figures, the node reached from $B$ on $X = 1$ is
labelled **$D$**, so the figure shows two distinct nodes both named $D$ and no node named $E$.

**Should be:** that node is **$E$**.

**Why:** the state table on slide 76 gives row $B$ the next states $D$ (on $X=0$) and $E$ (on $X=1$);
the mislabelled node's own successors on slide 78 are $J$ and $K$, which is $E$'s row, not $D$'s
($D$'s successors are $H$ and $I$); and the whole reduction on slides 79–81 depends on $E$ existing —
it concludes $E \equiv F$ and keeps $E$ in the reduced table. The slide-77 bullet even says "Now add
D, E, F, G" while the figure beside it shows D, D, F, G.

**Class:** substantive — a reader who works from the figure cannot follow the reduction on the next
four slides, and a state graph with two identically named nodes is not a well-formed graph.

### V09-2 · CH5 slide 98

**Prints:** in the $B^{+}$ K-map, the cell at $XA = 10$, $BC = 00$ contains **1**.

**Should be:** **0**.

**Why:** that cell is present state $ABC = 000 = S_0$ with input $X = 1$. The state table on slide 93
sends $S_0$ to $S_2$ on a 1, and $S_2$ is coded 001, so $B^{+} = 0$. Two things on the *same slide*
confirm it: the encoded next-state map beside the K-maps prints $S_2/001$ in exactly that position,
and the slide's own equation $B^{+} = X'C' + A'C + A'B$ evaluates to $0$ there. The $A^{+}$ and
$C^{+}$ maps both have the right bits in that cell (0 and 1), so only $B^{+}$ is wrong.

**Class:** substantive — taken as printed, row $BC = 00$ becomes all 1s and don't-cares, which invites
the grouping $B^{+} = B'C' + A'C + A'B$; that machine goes from $S_0$ to $S_4$ instead of $S_2$ on a
1 input, and the design no longer meets the state table.

### V09-3 · CH5 slide 101

**Prints:** $Z = XQ_2Q_3 + X'Q_2'Q_3 + XQ_2Q_3'$

**Should be:** $Z = XQ_2Q_3 + X'Q_2'Q_3 + X'Q_2Q_3'$ — the third term needs the prime on $X$.

**Why:** two cells of the slide's own $Z$ map contradict the printed equation. At $XQ_1 = 00$,
$Q_2Q_3 = 10$ (state $Q_1Q_2Q_3 = 010 = f$, input 0) the map holds 1 and the printed equation gives 0.
At $XQ_1 = 10$, $Q_2Q_3 = 10$ (state $f$, input 1) the map holds 0 and the printed equation gives 1.
The loop drawn on the slide's map covers the two left-hand cells of row $Q_2Q_3 = 10$, i.e. $X = 0$,
so the K-map grouping is correct and only the transcription slipped. With $X'$ restored the equation
matches the map at every defined cell. The gate and gate-input counts on the slide (10 and 26) are
unaffected and are correct.

**Class:** substantive — the printed equation asserts $Z = 1$ for state $f$ with input 1, where the
state table says $Z = 0$, and fails to assert it for state $f$ with input 0, where the table says
$Z = 1$. Two output errors.

### C09-1 · CH5 slide 86

**Prints:** the boxed conclusion "a ≡ d iff a ≡ d and c ≡ e".

**Should be:** "a ≡ d iff c ≡ e".

**Why:** the slide's own heading is "Self Redundant Pairs", and its bullet says the self-redundant
pair in square $a$-$d$ is removed. Once $a$-$d$ is struck out of its own square, the surviving
condition is $c \equiv e$ alone. As printed the statement is circular and states nothing.

**Class:** cosmetic — the chart itself carries the struck-out entry correctly, and the rest of the
worked example is unaffected.

### C09-2 · CH5 slide 91

**Prints:** "This is a n-p complete problem."

**Should be:** "This is an NP-complete problem."

**Why:** standard complexity-theory terminology; "NP" is an abbreviation for nondeterministic
polynomial time and is not hyphenated between the letters.

**Class:** cosmetic — spelling only.
