# Chronology — World Civilization II

Every date the three sources give, in one place, each tagged to where it came from. **Bold** = the dates
worth memorising outright. `[added]` = supplied by us, not in any source — usually because a correction
needed an anchor. `⚠` = the source's own date is wrong; the corrected date is shown and the flag names the
log entry.

|---|---|---|

## The seven coalitions

The sources name seven but describe only some. What can be stated from them:

| Coalition | Formed | Members named in the sources | Source |
|---|---|---|---|
| First | early 1793 | Austria, Prussia, Spain, the United Provinces, Great Britain | ·RNW ¶4 |
| Second | 1799 | Britain, Russia, the Ottoman Empire, Naples, Portugal, Austria | ·RNW ¶8 |
| Third | 1805 | Britain, Russia, Austria — Prussia joins in 1806 | ·RNW ¶8 |
| Fourth-Sixth | — | **not described** — the sources say "seven coalitions" but detail only these and the last | ·RNW ¶4 |
| Seventh | 1815 | Great Britain, Russia, Prussia, Austria | ·RNW ¶12 |
