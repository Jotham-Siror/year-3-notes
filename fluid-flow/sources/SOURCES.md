# Source material — Fluid Flow (MEC 3104 Fluid Theory)

The files listed below are **lecturer-authored course material and commercially published
textbooks**. They are deliberately **not tracked in version control** — we did not write them, and
this repository carries only work we authored ourselves.

This manifest exists so anyone with the repository can reconstruct `sources/` from their own copies.
Every `·slide N` citation in the knowledge base then resolves against the same deck.

## Where to obtain these

The deck comes from the lecturer through the usual course channels. The textbooks are standard fluid
mechanics references available through the university library.

## How to install them

```
fluid-flow/
└── sources/
    ├── SOURCES.md                          ← this file (tracked)
    ├── MEC 3104 FLUID THEORY - newlypasted.pdf
    ├── MEC 3104 FLUID THEORY NOTES.pptx
    └── textbooks/
        ├── Fluid_Mechanics_by_John_F.Douglas.pdf
        ├── Rajput_fluids.pdf
        ├── Fluid%20Mechanics.pdf
        └── fundamentals of fluid  mechanicsMunson Young(Autosaved).pdf
```

Keep both decks' **exact filenames** and do not re-order slides — the knowledge base cites slide
numbers throughout.

## Do the notes work without them?

**Yes.** All 561 slides of the Oct 2026 edition — and everything from the Jul 2026 edition that it
dropped — are transcribed into `../knowledge-base/`, with equations checked against the rendered
slides. You need a deck only to check a citation against the original slide.

**Total not tracked: ~152 MB.** The knowledge base that replaces it is under 250 KB.
