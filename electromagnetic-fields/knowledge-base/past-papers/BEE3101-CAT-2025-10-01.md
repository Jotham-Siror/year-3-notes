### Q2b · Worked solution · `[added]` — solved and verified 8 Oct 2026

Method: `../04-computational-em.md` §§ 5–7 — the five-node formula, newest values, start from zero.

**Boundary reading.** 60 V on the whole top, 40 V on the whole left, 20 V on the whole right, 0 V on the
whole bottom. No node touches a corner, so the "gap" strokes never enter.

**Step 1 · The four node equations.** Each free node is the average of its four neighbours:

$$V_1 = \tfrac{1}{4}\left(60 + 40 + V_2 + V_3\right)$$

$$V_2 = \tfrac{1}{4}\left(60 + 20 + V_1 + V_4\right)$$

$$V_3 = \tfrac{1}{4}\left(40 + 0 + V_1 + V_4\right)$$

$$V_4 = \tfrac{1}{4}\left(20 + 0 + V_2 + V_3\right)$$

**Step 2 · First iteration**, all free nodes starting at 0 V:

$$V_1 = \tfrac{1}{4}(60 + 40 + 0 + 0) = 25$$

$$V_2 = \tfrac{1}{4}(60 + 20 + 25 + 0) = 26.25$$

$$V_3 = \tfrac{1}{4}(40 + 0 + 25 + 0) = 16.25$$

$$V_4 = \tfrac{1}{4}(20 + 0 + 26.25 + 16.25) = 15.625$$

**Step 3 · Second iteration:**

$$V_1 = \tfrac{1}{4}(60 + 40 + 26.25 + 16.25) = 35.625$$

$$V_2 = \tfrac{1}{4}(60 + 20 + 35.625 + 15.625) = 32.8125$$

$$V_3 = \tfrac{1}{4}(40 + 0 + 35.625 + 15.625) = 22.8125$$

$$V_4 = \tfrac{1}{4}(20 + 0 + 32.8125 + 22.8125) = 18.9063$$

**Step 4 · All five iterations** (re-computed, 4 d.p.):

| Iteration | $V_1$ | $V_2$ | $V_3$ | $V_4$ |
|---|---|---|---|---|
| 1 | 25.0000 | 26.2500 | 16.2500 | 15.6250 |
| 2 | 35.6250 | 32.8125 | 22.8125 | 18.9063 |
| 3 | 38.9063 | 34.4531 | 24.4531 | 19.7266 |
| 4 | 39.7266 | 34.8633 | 24.8633 | 19.9316 |
| **5** | **39.93 V** | **34.97 V** | **24.97 V** | **19.98 V** |

**Check.** Solving the four equations exactly gives $V_1 = 40$, $V_2 = 35$, $V_3 = 25$, $V_4 = 20$ V.
After five iterations every node is within 0.07 V of these. The question is built to come out to whole
numbers.

**Sanity checks.** Every value lies between 0 and 60 V. The node nearest the 60 V and 40 V sides ($V_1$) is
highest; the node nearest the 20 V and 0 V sides ($V_4$) is lowest.

> **The pen table on the photographed paper** goes wrong at node 3. Its first column (25, 26.25, 21.25,
> 16.875) and every later column match exactly what you get if node 3 is given **20 V** below it instead of
> **0 V**: $V_3 = \tfrac{1}{4}(40 + 20 + 25 + 0) = 21.25$. The pen algebra at the foot of the page writes
> node 3's equation correctly, as $10 + (V_1 + V_4)/4$; the slip is in the numbers. With 0 V the answers
> are 40, 35, 25, 20 V. *(Re-computed: the 20 V slip reproduces ten of the twelve pen figures exactly; the other two, 36.815 and 40.403, are 36.875 and 40.469 with the last digits misread or miscopied.)*
