### Q5c · Worked solution · `[added]` — solved and verified 8 Oct 2026

Method: `../04-computational-em.md` §§ 5–7 — the five-node formula, newest values, start from zero.

**Boundary reading — say this in the answer.** The re-entrant corner $(x_2, y_1)$ is a neighbour of nodes 1
and 3, and the figure gives it no value (erratum P33). It is the end point of the 20 V edge, so it is taken
as **20 V** here. Everything else is as printed: 20 V on both top edges, 40 V on the right, −10 V on the
left, 0 V on the bottom.

**(i) · Expressions for the potentials at points 1–4** *(4 marks)*

Node neighbours (up, left, down, right):

| Node | Up | Left | Down | Right |
|---|---|---|---|---|
| 1 | 20 | corner, 20 | $V_4$ | 40 |
| 2 | 20 | −10 | 0 | $V_3$ |
| 3 | corner, 20 | $V_2$ | 0 | $V_4$ |
| 4 | $V_1$ | $V_3$ | 0 | 40 |

$$V_1 = \tfrac{1}{4}\left(20 + 20 + V_4 + 40\right) = \tfrac{1}{4}\left(80 + V_4\right)$$

$$V_2 = \tfrac{1}{4}\left(20 - 10 + 0 + V_3\right) = \tfrac{1}{4}\left(10 + V_3\right)$$

$$V_3 = \tfrac{1}{4}\left(20 + V_2 + 0 + V_4\right) = \tfrac{1}{4}\left(20 + V_2 + V_4\right)$$

$$V_4 = \tfrac{1}{4}\left(V_1 + V_3 + 0 + 40\right) = \tfrac{1}{4}\left(40 + V_1 + V_3\right)$$

**(ii) · Values after four iterations** *(6 marks)*

First iteration, all free nodes starting at 0 V:

$$V_1 = \tfrac{1}{4}(80 + 0) = 20$$

$$V_2 = \tfrac{1}{4}(10 + 0) = 2.5$$

$$V_3 = \tfrac{1}{4}(20 + 2.5 + 0) = 5.625$$

$$V_4 = \tfrac{1}{4}(40 + 20 + 5.625) = 16.4063$$

Second iteration:

$$V_1 = \tfrac{1}{4}(80 + 16.4063) = 24.1016$$

$$V_2 = \tfrac{1}{4}(10 + 5.625) = 3.9063$$

$$V_3 = \tfrac{1}{4}(20 + 3.9063 + 16.4063) = 10.0781$$

$$V_4 = \tfrac{1}{4}(40 + 24.1016 + 10.0781) = 18.5449$$

All four iterations (re-computed, 4 d.p.):

| Iteration | $V_1$ | $V_2$ | $V_3$ | $V_4$ |
|---|---|---|---|---|
| 1 | 20.0000 | 2.5000 | 5.6250 | 16.4063 |
| 2 | 24.1016 | 3.9063 | 10.0781 | 18.5449 |
| 3 | 24.6362 | 5.0195 | 10.8911 | 18.8818 |
| **4** | **24.72 V** | **5.22 V** | **11.03 V** | **18.94 V** |

**Check.** Solving the four equations exactly gives $V_1 = 24.74$, $V_2 = 5.26$, $V_3 = 11.05$,
$V_4 = 18.95$ V. After four iterations every node is within 0.05 V.

**Sanity checks.** Every value lies between −10 and 40 V. Node 1, boxed in by 20 V, 20 V and 40 V, is
highest; node 2, next to the −10 V wall and the 0 V floor, is lowest.

**How much the corner reading matters** (exact values, re-computed):

| Corner taken as | $V_1$ | $V_2$ | $V_3$ | $V_4$ |
|---|---|---|---|---|
| **20 V** (used above) | 24.74 | 5.26 | 11.05 | 18.95 |
| 10 V | 21.87 | 4.50 | 7.99 | 17.46 |
| 0 V | 19.00 | 3.73 | 4.93 | 15.98 |
